## 2. 讀的時候發現、要請使用者決定的事

1. **有些售電業的「電業收入」看起來只是服務費**
   - 中曜（2024、2025）、台汽電綠能（2020～2025）、大同智能（2024、2025）、星星電力（2022）：電業收入 ÷ 售電量只有每度 **0.1～0.8 元**，但購電量和售電量互相對得上，不是讀錯。
   - 合理的解釋：它們只認列媒合或代辦的服務費，不是全額賣電的收入。
   - 這些業者用「電業收入 ÷ 售電量」算售電單價會非常低，**網站上不適合顯示售電單價**。建議顯示「每度服務收入」或不顯示，請使用者決定。
2. **發電業有一半以上有收支表**
   - 先前以為發電業沒有財務數字（wpd 的風場確實沒有），但辰亞、厚固、辰華、茂正、天衝、天篷、曄恆、台灣艾貴都有收支表。
   - 算出來「電業收入 ÷ 售出電量」大約每度 **4.8～5.8 元**，看起來合理。
   - 要不要在網站上顯示發電業的「每度售電收入」，請使用者決定。
3. **營業成本不一定等於購電成本**：例如富威 2021，營業成本 ÷ 購電量約每度 15.7 元，營業成本裡有其他費用。網站上要寫清楚「購電成本」是推估。

## 4. 怎麼讀的

1. 從資料庫的 `company_reports` 取出 94 份「找到」的年報，逐份下載到暫存資料夾（PDF 不放進專案），讀完就可以刪。
   - Google 雲端硬碟、Box、富威的檔案主機：2026-11-26 使用者同意後開放網路。
   - 天衝、天篷：連結是限時的，用瀏覽器按年份、馬上下載；中曜：用網站自己的下載功能。
   - 台汽電、陽光伏特家：連結是網頁，從網頁裡找 PDF；康展電力：年報直接寫在公告網頁裡（沒有 PDF、沒有頁碼）。
2. 用程式把 PDF 轉成文字，依能源署年報格式的表格名稱找「合計」那一行：
   - 售電業：購電量（表 2-1／2-3）、售電量（表 2-2／2-4）、收支實績表（營業收入、電業收入、營業成本、營業費用）。
   - 發電業：裝置容量（表 1-1／3-1）、毛發電量和淨發電量（表 1-2／3-2）、容量因數（運作情形表）、
     售予台電（表 2-1／4-1）、售予再生能源售電業（表 2-2）、直／轉供予用戶（表 2-3／4-4）、收支實績表。
   - 每份都人工看過「合計」那一行屬於哪張表，避開「未來 10 年購電計畫」這類預估表。
3. 規則：
   - 遮蔽（`*`、`x`）→ 空值；表格寫「-」→ 0（備註有寫）；單位千元 → 換成元。
   - 沒有合計的表格不自己加總，存空值並在備註寫原因（規格：不要用其他數字推算）。
   - 和其他數字對不起來的照報告記錄，在備註寫出來並列入第 3 節的抽查清單。
4. 掃描檔：大同智能 2024、2025 後半段是掃描的財務報告，不需要用到；艾涅爾 2024、2025 的收支表是圖片，用 OCR（tesseract 繁體中文）辨識再看圖確認。
5. 合理性檢查：售電業算「電業收入 ÷ 售電量」、「營業成本 ÷ 購電量」，發電業算「電業收入 ÷ 售出電量」，超出每度 2～8 元的都逐一查過原因（第 2、3 節）。

## 5. CSV 欄位

| 欄位 | 說明 |
|---|---|
| `company_id`、`company_short`、`role`、`year`、`period`、`report_id` | 業者、年度、對應 `company_reports` 的報告編號（`period` 都是 `annual`） |
| `page` | 主要的頁碼（有收支表就是收支表那一頁） |
| `purchased_kwh`、`sold_kwh` | 售電業：購電量、售電量（度） |
| `capacity_kw`、`gross_generation_kwh`、`net_generation_kwh` | 發電業：裝置容量（瓩）、毛發電量、淨發電量（度） |
| `sold_to_taipower_kwh`、`sold_to_retailers_kwh`、`sold_to_users_kwh` | 發電業：售予台電（公用售電業）、售予再生能源售電業、直／轉供予用戶（度） |
| `capacity_factor_pct` | 發電業：容量因數（%） |
| `operating_revenue`、`electricity_revenue`、`operating_cost`、`operating_expense` | 收支實績表：營業收入、電業收入、營業成本、營業費用（元） |
| `pages` | 每個數字在第幾頁，例如「購電量 p5；售電量 p6；收支表 p10」 |
| `source` | `pdf`／`html`（康展的公告網頁）／`missing`（讀不到） |
| `scanned`、`masked` | 有掃描頁或圖片表格；收支表有遮蔽（Y） |
| `note` | 這份要注意的地方 |

`company_short`、`role`、`pages`、`source`、`scanned`、`masked` 是方便抽查用的；匯入資料庫時再決定哪些欄位要存。
